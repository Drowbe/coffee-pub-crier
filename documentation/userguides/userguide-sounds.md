# Sounds

**Audience:** the GM setting up a world.

Crier can play a sound with each card it posts. There are four, each set separately, and each can be
silenced on its own.

## The four sounds

| Sound | Plays | Set under |
|---|---|---|
| **Combat Start Sound** | when a fight begins | Combat Configuration |
| **Combat End Sound** | when a fight ends | Combat Configuration |
| **Round Start Sound** | at the top of each round | Round Configuration |
| **Turn Start Sound** | at the start of every turn | Turn Configuration |

![The Combat Configuration settings, including Combat Start Sound and Combat End Sound](../assets/crier-settings-combat.webp)

## Silence one

Every sound dropdown has a *None* option. Choose it and that card posts silently; the card itself is
unaffected.

**The turn sound is the one to look at first.** It fires on every combatant's turn, which in a large
fight is many times a round -- it is the sound tables tire of soonest. The round and combat sounds
fire once each and tend to survive.

## Sounds stack with other modules

Crier does not claim a sound slot. If another module also plays something at the start of a turn or
a round, both play. If you are hearing a double, check the other module before changing this one.

## Where the list comes from

The sound list is Blacksmith's. When Blacksmith adds sounds they appear here without Crier changing.

A sound plays only after its card has actually posted, so a card held back waiting on initiative is
silent until it goes out.
